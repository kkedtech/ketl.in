# ketl.in

The KETL India website, served by GitHub Pages at **ketl.in**.

This is a copy of the India page from the main `kkedtech/ketl` repository
(`docs/in/index.html`, served at ketl.au/in), adjusted to run from the site
root:

- `assets/` and `uploads/` paths are relative to the root
- links to Australian-only pages (AI for Adolescents, Gallery, Terms) point
  to https://ketl.au

When `docs/in/index.html` changes in `kkedtech/ketl`, copy the change here
too so both addresses stay the same.

India pages use the kangaroo + peacock logo only; never the kangaroo-only
Australian logo.
